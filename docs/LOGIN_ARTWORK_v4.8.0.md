# Login artwork and branding

Generation mode: built-in image generation with transparent background. Project asset: `app/src/main/res/drawable-nodpi/art_login_3d.png`.

Final prompt:

Use case: stylized-concept. Asset type: transparent 3D illustration for the login header of Study Sprint, a student focus and productivity Android app. Create one polished cohesive sculptural still life: an open ivory notebook with mint and deep emerald cover, an emerald graduation cap hovering just above the book, and a small matching rounded focus timer tucked beside the book. Two small restrained gold sparkles. Soft matte ceramic-like materials with subtle glossy emerald edges, warm gentle studio lighting, clean friendly high-quality 3D product render, balanced centered composition readable at 160dp wide. Palette deep emerald #0BA982, mint #D6F4E7, ivory #F8F7F0, restrained gold. Transparent background with actual alpha; no backdrop, no base/platform, no text, no lettering, no logo, no watermark. Fully contain all objects inside the canvas with generous transparent margins.

The PNG is copied unchanged with its alpha channel. The app logo is a native Android vector (`app/src/main/res/drawable/ic_launcher.xml`), with separate monochrome vector and adaptive launcher resources. Its book-and-cap identity uses the app's emerald, mint, ivory and gold palette. Login artwork is decorative and rendered with ContentScale.Fit; interactive controls remain native Compose.
