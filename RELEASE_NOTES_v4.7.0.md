# Study Sprint v4.7.0

- FocusIQ-inspired design throughout the native app: charcoal and emerald surfaces, Poppins typography, refined cards, clearer selected navigation and solid primary actions.
- New coordinated transparent 3D artwork for focus, study, protection and progress. Artwork is packaged offline and displayed separately from interactive controls.
- Original Study Sprint logo appears in page navigation and brand screens; your profile photo remains your profile photo.
- Home now shows daily goal progress with a clear progress bar and feature artwork; Tasks shows real completion counts beside notebook artwork.
- Focus uses a clean native circular track and centered countdown without bitmap offsets. The compact-screen layout keeps the Start button visible. Setup Skip/Next actions stay below scrolling content on small screens. Protection status and existing app limits remain available.
- Light, dark and system themes share the updated design. Existing study data and app-blocking behavior are retained.

Release checks: unit tests, release lint, Android navigation/enforcement tests and Firebase rules tests.
